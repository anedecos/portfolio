Standards & practices in production
Not just a stack. A way of building.
Transactional outbox
Atomic event publication backed by a poller. Domain events never lost on a failed downstream, never double-published on retry.
Row-Level Security audit
Postgres RLS enforced via tenant transaction interceptor. Pre-merge scripts audit:rls-coverage and audit:rls-bypass catch any drift before it lands.
OpenAPI as contract
Spec generated from controllers, verified in CI via openapi:check. SDK and downstream frontends regenerate from a single source of truth.
Endpoint contract audit
Custom static analyzer (audit:endpoint-contracts) ensures every endpoint follows the same response envelope, error shape and DTO conventions.
Domain events + capability registry
Typed events emitted on every domain mutation. Modules subscribe through a capability registry, no hidden coupling, no spaghetti listeners.
Activity log on every mutation
Global interceptor logs every POST/PATCH/PUT/DELETE with request-id on an independent EM context. Fire-and-forget, zero per-handler boilerplate.
Real-DB integration tests
Tests boot the full Nest app with a real database, sequential workers, table truncation between cases. Mocks only at vendor boundaries.
k6 performance suite
Load and stress scripts versioned with the codebase, run against a real database. Performance regressions caught before users feel them.
Migration discipline
Single clean baseline plus versioned incremental migrations. Every environment reproduces exactly. No silent schema drift.

Section 5 · Architectural thinking

Decisions that define a system

These are the engineering rules I apply on every system I design and lead. Each one earned in production, with real teams, at real scale.

01
Defense-in-depth multi-tenancy

Tenant isolation isn't a single guard. It's three independent layers: ORM filter, explicit repository scoping, and PostgreSQL RLS. If one is bypassed, the other two still hold.

02
Vendor-agnostic infrastructure

Auth, storage, realtime, payments, all behind DI tokens with typed interfaces. Switching a provider is a one-class change, not a rewrite. No vendor lock-in by default.

03
Typed error contracts

Domain errors as BusinessException + ErrorCode enum (30+ codes). The frontend consumes structured errors, not strings. No magic numbers, no parsing prose.

04
Clean architecture boundaries

Controllers → Services → Repositories. The only layer touching the EntityManager is the repository. No shortcuts. Guards and interceptors delegate to services. Boundaries are enforced, not suggested.

05
Audit by default

A global activity-log interceptor on every mutation, fire-and-forget, with an independent EM context. Zero per-handler boilerplate, full traceability across every request.

06
Migration discipline

A single clean baseline migration is the source of truth. New schema = versioned migrations, no schema:update --run drift. Every prod environment can be reproduced exactly.

07
Domain-driven module boundaries

Modules export only services, never repositories or ORM features. Cross-module access is explicit, intentional, and reviewable. The dependency graph stays understandable.

08
Observability as a first-class concern

Request-id middleware on every route. Structured response envelope. Distributed tracing (correlation + service + transaction ID) on a search engine. Debugging time collapses from hours to minutes.

09
Test what would actually fail

Integration tests boot the full Nest app with a real database, sequential workers, table truncation between tests. Mocks only at vendor boundaries (e.g. MockPaymentProvider) so what we test mirrors production.
